# Tune 1.4.1

This release is **unsigned**, as explicitly approved by the owner. Windows may show an unknown-publisher or SmartScreen warning. SHA256SUMS.txt contains the download checksums.

הגרסה מפורסמת **ללא חתימה דיגיטלית**, באישור מפורש של הבעלים. Windows עשוי להציג אזהרת מפרסם לא מוכר או SmartScreen. הקובץ SHA256SUMS.txt מכיל את ערכי האימות של ההורדות.

English:
- A cleaner, more spacious interface across all ten screens in English and Hebrew. Original font sizes are preserved; secondary details expand on request, while actions and warnings stay visible. All existing features remain available.
- A denied Windows start-up timing log is reported as requiring administrator permission, never as an empty log; old measurements stay historical.
- Sensor values expire when stale. Requested VID is distinguished from measured core voltage, GPU fan readings match by device name, and performance gauges remain live only while readings arrive.
- Service 11 records operation IDs and results durably. History can recover a lost answer without repeating the change; interrupted or missing results remain unconfirmed. Partial driver results are displayed separately.
- Official downloads are restricted across redirects. BIOS and graphics package offers need matching device/firmware evidence.
- Dependencies updated; the lockfile is reproducible and audited in CI. Release publication requires full CI on the same commit. The owner approved unsigned publication for 1.4.1 only.
- Licensing remains unconfigured with the open policy. No payment service is enabled.

עברית:
- ממשק נקי ומרווח יותר בכל עשרת המסכים, בעברית ובאנגלית. גדלי הכתב המקוריים נשמרו; פרטים משניים נפתחים לפי הצורך, והפעולות והאזהרות נשארות גלויות. כל הפיצ׳רים הקיימים נשמרו.
- יומן זמני עלייה שחסום לקריאה מוצג כדרישת הרשאת מנהל. מדידות קודמות נשארות היסטוריות.
- קריאות חיישנים ישנות מוסתרות, VID מסומן בנפרד ממתח ליבה, ונתוני GPU מותאמים לפי שם הכרטיס.
- שירות 11 שומר מזהי פעולות ותוצאות. ההיסטוריה משחזרת תשובה שאבדה בלי לבצע שוב את השינוי; תוצאה חסרה או פעולה שנקטעה אינן מוצגות כהצלחה. התקנת דרייברים חלקית מוצגת בנפרד.
- הורדות רשמיות מוגבלות גם בהפניות, והצעת BIOS או דרייבר דורשת התאמה לדגם ולמשפחת הקושחה.
- התלויות עודכנו ונבדקות ב־CI. פרסום גרסה דורש את כל בדיקות Windows על אותו קומיט. הבעלים אישר פרסום ללא חתימה לגרסה 1.4.1 בלבד.
- הרישוי נשאר לא מוגדר ובמדיניות open; לא הופעלה מכירה.

After updating, approve the background-service update in Tune when offered, or choose Later. The new service is version 11; until it is updated, Tune uses Windows' administrator approval for changes.

אחרי העדכון, אשר את עדכון שירות הרקע כש־Tune מציע אותו, או בחר ״אחר כך״. השירות החדש הוא בגרסה 11; עד שיעודכן, שינויים יבוצעו באמצעות אישור המנהל של Windows.

## Tune 1.4.0

Tune 1.3.1 offers this update in Settings. After the update, Tune asks once to update its background service too (**Update**, or **Later**); that needs administrator approval, and until then changes go through Windows' approval prompt. Not signed yet (no code-signing certificate), so when installing from this page Windows SmartScreen may warn: **More info → Run anyway**.

New:
- **Fix a problem**: pick what bothers you (Windows starts slowly, games don't run smoothly, the PC gets hot) and Tune shows what it measured, what may be the cause and what it couldn't check. Measurements before and after an action are compared only when taken the same way.
- **A safer background service (version 8)**: only an administrator of this PC can ask it to change anything; every change runs contained, with a time limit, and is confirmed stopped before the next one starts; it installs into its own protected folder, checked file by file, and an update that doesn't start is rolled back.
- **No script files for elevation**: the steps that need administrator rights no longer run from files a user could change.
- **An older background service is never used for changes**: if one is found, Tune offers to update it and uses Windows' approval prompt until then.
- Settings shows the licence section; licensing is not open in this version and every feature stays available.

## Tune 1.4.0

Tune 1.3.1 מציע את העדכון הזה בהגדרות. אחרי העדכון Tune יבקש פעם אחת לעדכן גם את שירות הרקע שלו (**עדכן**, או **אחר כך**); זה דורש אישור מנהל, ועד אז שינויים עוברים דרך חלון האישור של Windows. הגרסה עוד לא חתומה (אין תעודת חתימת קוד), ולכן בהתקנה מהעמוד הזה SmartScreen של Windows עשוי להזהיר: **מידע נוסף ← הפעל בכל זאת**.

חדש:
- **פתרון בעיה**: בוחרים מה מפריע (Windows עולה לאט, משחקים לא רצים חלק, המחשב מתחמם), ו-Tune מראה מה מדד, מה יכול להיות הגורם ומה לא הצליח לבדוק. מדידות לפני ואחרי פעולה מושוות רק כשנמדדו באותו אופן.
- **שירות רקע בטוח יותר (גרסה 8)**: רק מנהל של המחשב יכול לבקש ממנו לשנות משהו; כל שינוי רץ מבודד, עם מגבלת זמן, ומאומת שנעצר לפני שהבא מתחיל; הוא מותקן לתיקייה מוגנת משלו, נבדק קובץ אחר קובץ, ועדכון שלא עולה מוחזר לגרסה הקודמת.
- **בלי קובצי סקריפט להרשאות מנהל**: השלבים שדורשים הרשאות מנהל כבר לא רצים מקבצים שמשתמש יכול לשנות.
- **שירות רקע ישן לא משמש לשינויים**: אם נמצא כזה, Tune מציע לעדכן אותו, ועד אז משתמש בחלון האישור של Windows.
- בהגדרות מופיע אזור הרישיון; הרישוי עוד לא פתוח בגרסה הזו וכל היכולות נשארות זמינות.

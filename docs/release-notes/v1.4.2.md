# Tune 1.4.2

- AMD Radeon desktop RX 5000/6000/7000/9000 driver checks now use the official page for the exact model and Windows edition, and its recommended WHQL package. Installed Adrenalin release numbers and Windows driver numbers are compared only within the same namespace. Ambiguous results remain unchecked; AMD's official auto-detect tool remains available.
- Transient graphics-catalog failures are retried once with a bounded timeout.
- The sidebar fits all ten destinations at the minimum 980 × 640 content size without scrolling. Font sizes are unchanged; row padding and group spacing are smaller.
- Liquid Glass accounts for left-side RTL scrollbars and updates when its group changes size.
- A failed graphics check also shows an incomplete status in the sidebar instead of a green completed status, and retains a link to the official source.

This release is unsigned, as explicitly approved by the owner. Windows may show an unknown-publisher or SmartScreen warning. SHA256SUMS.txt contains download checksums.

Tune checks for updates automatically after launch and every four hours. Choose Update now to download, then Restart and install when ready. Full Windows CI must pass for the exact release commit before publication.

# Tune 1.4.2

- בדיקת דרייבר AMD לכרטיסי Radeon RX שולחניים מסדרות 5000/6000/7000/9000 משתמשת בדף הרשמי לדגם ולגרסת Windows, ובחבילת WHQL המומלצת. גרסת Adrenalin וגרסת הדרייבר של Windows מושוות כל אחת לסוג המתאים. כשאין התאמה ודאית, הבדיקה נשארת לא מאומתת וכלי הזיהוי הרשמי של AMD נשאר זמין.
- כשל זמני בגישה לקטלוג הדרייברים מקבל ניסיון חוזר מוגבל בזמן.
- כל עשר אפשרויות התפריט נכנסות בחלון המינימלי 980 × 640 ללא גלילה. גדלי הכתב לא שונו; הריווח וגובה השורות צומצמו.
- אפקט Liquid Glass מתחשב בפס גלילה בצד שמאל בעברית ומתעדכן כשגודל הקבוצה משתנה.
- כשל בבדיקת כרטיס המסך מוצג גם בסטטוס הצדדי, במקום סטטוס ירוק של סריקה שהושלמה, עם קישור למקור הרשמי.

הגרסה מפורסמת ללא חתימה דיגיטלית באישור מפורש של הבעלים. Windows עשוי להציג אזהרת מפרסם לא מוכר או SmartScreen. הקובץ SHA256SUMS.txt מכיל ערכי אימות להורדות.

Tune בודק עדכונים אוטומטית אחרי הפעלה ובכל ארבע שעות. בוחרים עדכון כדי להוריד, ואז הפעלה מחדש והתקנה כשההורדה מוכנה. פרסום הגרסה דורש שכל בדיקות Windows יעברו על קומיט השחרור עצמו.
